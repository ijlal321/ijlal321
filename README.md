# Hi there, I'm Muhammad Ijlal! 👋

I am a Graphics programmer, I am very intrested in Unity development, specializing in custom render pipelines,
performance optimization, and advanced shaders. I also love real-time graphics, blending strong engineering with creative problem-solving.
